Homelab — Privacy Policy

Effective date: July 4, 2026 · Arilab Studios

Homelab — Server Dashboard ("the app") is a personal dashboard for self-hosted services. It is designed to collect no personal data whatsoever.

Data collection

The app does not collect, store, transmit or share any personal information, usage analytics, identifiers, or diagnostics. There are no user accounts, no third-party SDKs, no advertising, and no tracking of any kind.

Network access

The app's only network activity is issuing HTTPS status checks (HEAD requests) to the homelab services it displays, and opening those services in a browser tab when you tap a card. These requests contain no personal data beyond what any web browser sends when contacting a website.

Permissions

The app requests a single Android permission: INTERNET, used solely for the status checks described above.

Children

The app is a utility, is not directed at children, and collects no data from anyone, including children.

Changes

If this policy ever changes, the updated version will be posted at this URL.
